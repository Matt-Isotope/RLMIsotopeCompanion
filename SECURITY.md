# Security

Please do not include the following in bug reports or shared examples:

- passwords;
- API keys;
- authentication tokens;
- personal data;
- patient or participant information;
- confidential research material;
- unpublished sensitive data;
- proprietary source code.

The addin sends selected R code to the configured LM Studio server.
Users are responsible for checking the selected code and the server
configuration before sending a request.

The default server address is:

`http://localhost:1234/v1`
